# Connect Four - Python

A simple two-player Connect Four game built with Python and Tkinter.

## Features

- 6 x 7 Connect Four board
- Two-player local gameplay
- Automatic turn switching
- Horizontal, vertical, and diagonal win detection
- Draw detection
- New Game button
- Simple graphical interface

## Requirements

- Python 3.x
- Tkinter (usually included with standard Python installations)

## How to Run

1. Make sure Python is installed.
2. Open a terminal in this project folder.
3. Run:

```bash
python main.py
```

On some systems, use:

```bash
python3 main.py
```

## How to Play

- Player 1 uses red pieces.
- Player 2 uses yellow pieces.
- Click a column to drop your piece.
- The piece falls to the lowest available position.
- Connect four pieces horizontally, vertically, or diagonally to win.
